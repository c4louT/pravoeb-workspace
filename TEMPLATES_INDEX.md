# TEMPLATES_INDEX.md — Навигатор по шаблонам договоров

При создании договора:
1. Определи тип по таблице ниже
2. Открой шаблон из contracts/templates/
3. Заполни все поля в [скобках]
4. Проверь по чеклисту из CONTRACTS.md
5. Сконвертируй в .docx через tools/to_docx.py
6. Отдай с правильным названием файла

| Ситуация | Файл |
|---|---|
| Актёр/актриса, передача смежных прав | contracts/templates/01_Договор_с_актером.md |
| Режиссёр-постановщик | contracts/templates/02_Договор_с_режиссером.md |
| Сценарист/композитор по заказу + отчуждение | contracts/templates/03_Договор_авт_заказа_отчуждение.md |
| Готовое произведение, права передаются полностью | contracts/templates/04_Договор_об_отчуждении.md |
| Права на срок, автор их не теряет | contracts/templates/05_Лицензионный_договор.md |
| Участник съёмок, согласие + права на результаты | contracts/templates/06_Согласие_съемка_изображение.md |
| Оператор-постановщик | contracts/templates/07_Договор_с_оператором.md |

## Отчуждение vs Лицензия
Отчуждение — автор теряет права навсегда. Как продажа. Нужно для кино почти всегда.
Лицензия — права на время. Как аренда. Для чужой музыки/фото когда автор не готов отдавать насовсем.
