# STYLE_GUIDE.md — Стиль оформления договоров продюсера

Этот файл создан на основе анализа реальных договоров из практики.
При составлении любого договора — следовать этим правилам.

---

## 1. СТРУКТУРА И ЯЗЫК

### Преамбула
Стандартная формула для физлица-продюсера:
```
[ФИО Продюсера], именуемая(ый) в дальнейшем «Продюсер», с одной стороны, и
[ФИО Актёра], именуемый(ая) в дальнейшем «Актёр», с другой стороны,
совместно именуемые «Стороны», заключили настоящий Договор о нижеследующем:
```

Для юрлица-студии:
```
[Наименование], именуемое в дальнейшем «Студия», в лице [должность ФИО],
действующего на основании [Устава/доверенности], с одной стороны, и...
```

### Язык договора
- Официально-деловой, без канцелярита в обычном тексте
- Роли сторон — **жирный курсив** при первом упоминании
- Определения терминов — в кавычках: «Фильм», «Исполнение», «Трактовка»
- Ссылки на ГК — конкретные статьи, не общие отсылки

## 2. ФОРМУЛИРОВКИ ПЕРЕДАЧИ ПРАВ

### Главный принцип из реальных договоров:
Права передаются максимально широко, без ограничений — это стандарт в кино.

### Передача смежных прав актёра (проверенная формулировка):
```
Заключение настоящего Договора в соответствии со статьями 1304, 1307, 1313,
1314, 1317 ГК РФ влечёт отчуждение Актёром Продюсеру исключительных прав
в полном объёме на использование его Исполнения любыми способами во всём мире
и на весь срок действия исключительных прав на исполнение (бессрочно),
как в рамках использования Фильма (в составе Фильма), так и отдельно от него.
```

### Ключевая формула закрепления прав:
```
Актёр отчуждает все исключительные права в отношении любых и всех результатов
своей работы по созданию Исполнения без каких-либо оговорок, ограничений,
исключений, изъятий, и никакие исключительные права не сохраняются за Актёром.
```

### Момент перехода прав (важно!):
```
Все отчуждаемые по Договору права закрепляются за Продюсером в момент создания
Исполнения и остаются законными вне зависимости от того, истечёт ли срок
действия настоящего Договора обычным путём или он будет аннулирован.
```

### Передача прав оператора-постановщика:
```
Заключение настоящего Договора, в соответствии со ст. 1234, 1240, 1263, 1270
ГК РФ, влечёт отчуждение Оператором-постановщиком всех исключительных прав
на Трактовку, созданную в процессе работы над Фильмом, в полном объёме Продюсеру.
Переданное право принадлежит Продюсеру без каких-либо территориальных,
временных или иных ограничений.
```

### Права на будущие способы использования:
```
...любыми способами и в любых формах, известных сегодня и могущих появиться
в будущем...
```
Эта фраза — обязательна. Без неё могут возникнуть споры при новых технологиях дистрибуции.

## 3. ПРАВА НА ИМЯ, ИЗОБРАЖЕНИЕ, ГОЛОС

Стандартный блок для договора с актёром:
```
Актёр передаёт Продюсеру исключительные права на использование созданного им
образа персонажа Фильма, голоса, имени (творческого псевдонима), своего
изображения в образе данного персонажа, образца подписи, биографических данных,
исполнения, его фрагментов и элементов, как включённых, так и не включённых
в окончательную версию Фильма, в любой форме и любыми способами, в том числе
для рекламы, создания и распространения сувениров, игр и иных товаров
на территории всего мира без ограничения срока.
```

### Реклама и продвижение:
```
Продюсеру предоставляется право использовать имя и портрет Актёра для рекламы,
публикации и использования Фильма без ограничения срока и территории.
```

### Обязательства по участию в рекламе:
```
Актёр обязуется участвовать во всех рекламных мероприятиях (пресс-конференциях,
радио- и телепередачах, интервью и т.д.), организуемых Продюсером.
```

## 4. ПРАВА ПРОДЮСЕРА КАК ИЗГОТОВИТЕЛЯ АВП

Стандартный блок, подтверждающий статус Продюсера:
```
Имеется понимание Сторон, что Продюсер является обладателем исключительных
прав на Фильм и вправе передавать такие права третьим лицам.

Продюсер имеет исключительное право на:
- изменение последовательности кадров;
- замену действующих лиц в Фильме;
- изменение содержания и названия Фильма;
- использование Фильма или его частей для создания новых произведений,
  в том числе аудиовизуальных;
- использование отдельно звука и изображения, зафиксированных в Фильме,
  в том числе в переработанном виде.
```

## 5. ГАРАНТИИ ИСПОЛНИТЕЛЯ

Стандартный блок — обязателен в каждом договоре:
```
Актёр гарантирует, что на момент заключения настоящего Договора он не связан
никакими обязательствами, которые могут каким-либо образом воспрепятствовать
заключению настоящего Договора или надлежащему исполнению принятых на себя
обязательств по Договору.

Актёр гарантирует, что не примет на себя каких-либо обязательств перед
третьими лицами, которые могут воспрепятствовать надлежащему исполнению
обязательств по настоящему Договору.
```

---

## 6. ВОЗНАГРАЖДЕНИЕ

### Безвозмездный договор (студенческие проекты, короткий метр):
```
Актёр выполняет принятые на себя обязательства по настоящему Договору
на условиях — без выплаты вознаграждения.

Актёр не вправе претендовать на какие-либо отчисления/вознаграждения,
связанные с демонстрацией, тиражированием, любым иным использованием Фильма
Продюсером или иными третьими лицами.
```

### Возмездный договор:
```
Вознаграждение по настоящему Договору включает в себя:
- вознаграждение за оказание услуг по исполнению Роли;
- вознаграждение за исключительные права, полученные Продюсером.

Стороны договорились, что выплачиваемое вознаграждение полностью покрывает
вознаграждение за любое использование результатов услуг. Актёр не вправе
претендовать на участие в доходах от эксплуатации Фильма.
```

## 7. ОБЯЗАННОСТИ АКТЁРА — СТАНДАРТНЫЙ СПИСОК

Обязателен развёрнутый список, не краткий:
```
3.1.1. Выполнять все требования и условия настоящего Договора, в том числе
       режиссёра-постановщика, связанные с исполнением Роли.
3.1.2. Выполнять обязанности в точном соответствии с постановочным проектом,
       сценарием и общепринятыми в кинопроизводстве нормами.
3.1.3. Соблюдать правила охраны труда и техники безопасности, санитарные нормы,
       правила пожарной безопасности при производстве Фильма.
3.1.4. Точно выполнять указания и распоряжения режиссёра-постановщика Фильма.
3.1.5. Бережно относиться к имуществу Продюсера. В случае преднамеренной
       порчи или утери — полностью возмещать стоимость.
3.1.6. Не разглашать конфиденциальную информацию о Фильме.
3.1.7. Не предоставлять третьим лицам без письменного согласия Продюсера
       материалы, созданные в процессе производства Фильма.
3.1.8. Без предварительного письменного согласования с Продюсером не использовать
       созданный в Фильме образ роли в другом исполнении, в рекламных целях.
3.1.9. Не брать на себя обязательства перед третьими лицами, которые могут
       воспрепятствовать надлежащему исполнению обязательств по Договору.
```

## 8. ПРАВО ПРОДЮСЕРА НА ОТСТРАНЕНИЕ АКТЁРА

Обязательный пункт в правах Продюсера:
```
Продюсер имеет право отстранить Актёра от работы в случае:
- появления на съёмочной площадке в состоянии алкогольного или
  наркотического опьянения;
- грубого систематического (более 2-х раз) нарушения обязательств по Договору.
```

---

## 9. РАСТОРЖЕНИЕ ДОГОВОРА

### Форс-мажор со стороны Продюсера:
```
В случае наступления обстоятельств, не зависящих от Продюсера, которые вызывают
задержку, остановку или парализуют съёмку (в том числе длительная болезнь
Режиссёра-постановщика, Оператора-постановщика или исполнителей главных ролей),
Продюсер имеет право прервать работу в любой момент производства Фильма
и прекратить действие настоящего Договора.
```

### При досрочном расторжении права сохраняются:
```
Во всех случаях досрочного расторжения Договора Продюсер вправе использовать
результат творческой деятельности Актёра, а также фото- и кинопробы
в соответствии с условиями раздела [права].
```

### Конфликт на площадке:
```
В случае возникновения конфликта трудового, творческого или личностного
характера в съёмочной группе по вине Актёра, Продюсер вправе расторгнуть
Договор с сохранением всех выплаченных сумм.
```

## 10. ТИТРЫ

Стандартная формулировка:
```
Имя Актёра должно быть указано в титрах Фильма.
```

Для режиссёра — право убрать имя из титров при нарушении неприкосновенности:
```
Если Режиссёр посчитает нарушенным своё право на неприкосновенность произведения
внесёнными изменениями, он имеет право исключить своё имя из титров Фильма
или заменить его на псевдоним.
```

---

## 11. ЗАКЛЮЧИТЕЛЬНЫЕ ПОЛОЖЕНИЯ

Стандартный блок:
```
10.1. Во всём остальном, что не предусмотрено Договором, Стороны руководствуются
      действующим законодательством Российской Федерации.
10.2. Истечение срока действия Договора не освобождает от выплаты всех сумм
      вознаграждения, предусмотренных Договором.
10.3. С момента подписания Договора все предыдущие переговоры и переписка
      утрачивают силу.
10.4. Договор составлен в двух экземплярах на русском языке, по одному для
      каждой из сторон. Все экземпляры имеют одинаковую юридическую силу.
10.5. Все изменения, дополнения и приложения к Договору являются его
      неотъемлемой частью.
```
