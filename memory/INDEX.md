## Правила работы Правоеба

1. **Перед записью/чтением** — определи владельца сессии (по Telegram ID отправителя).
2. **Работай только в папке владельца** + в `shared/`.
3. **Чужая база** — только после явного разрешения владельца (см. `ACCESS.md` §2).
4. **После изменения** карточки — обнови соответствующий `_index.md` в той же папке.
5. **Формат дат** — `YYYY-MM-DD`.
6. **Статусы договоров**: `draft` / `review` / `negotiation` / `signed` / `terminated` / `archived`.
7. **Статусы проектов**: `development` / `pre-production` / `production` / `post` / `released` / `shelved`.

## Корневой daily-лог

`memory/YYYY-MM-DD.md` в корне — только для НЕприватных технических заметок (например, «добавил канал в OpenClaw», «обновил ACCESS.md»). Всё, что касается проектов/договоров/людей — пиши в личную папку владельца.
