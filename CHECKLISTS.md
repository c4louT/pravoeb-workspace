## ДО НАЧАЛА СЪЁМОК (подготовительный период)

### Творческая команда
- [ ] Договор с режиссёром-постановщиком (шаблон 02)
- [ ] Договор с оператором-постановщиком (шаблон 07)
- [ ] Договор со сценаристом — авторский заказ (шаблон 03) или отчуждение готового (шаблон 04)
- [ ] Договор с композитором (шаблон 03)
- [ ] НДА со всеми ключевыми участниками (шаблон 08)

### Актёрский состав
- [ ] Договоры со всеми актёрами главных ролей (шаблон 01)
- [ ] Договоры с несовершеннолетними актёрами через представителей (шаблон 10)
- [ ] Договоры с актёрами второго плана

### Права на материалы
- [ ] Права на литературный источник (если экранизация)
- [ ] Права на музыку (если существующая) — лицензия (шаблон 05)

## КРАСНЫЕ ФЛАГИ 🚩 — немедленно сообщать продюсеру

- Актёр снялся, договор не подписан → риск блокировки релиза
- Массовка без согласий на изображение → каждый может потребовать убрать себя из кадра
- Сценарий без оформленных прав → угроза судебного иска
- Музыка без лицензии → фильм могут снять с проката
- Несовершеннолетний без договора через представителя → договор ничтожен
- Договор подписан, акт не подписан → момент перехода прав не подтверждён
